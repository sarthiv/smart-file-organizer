SMART FILE ORGANIZER
MODULE 12 — ACTIVITY LOGGING & HISTORY

1. GOAL
This module records important application activities such as folder scanning, file organization, duplicate detection, and duplicate movement. Logs are stored in backend/logs/activity.log.

2. PYTHON LOGGING
The project uses Python's built-in logging module.
Important concepts:
- logging: records application events.
- INFO: records normal informational events.
- filename: selects the log file.
- format: controls log structure.
- logger: object used to write messages.

Example:
logger.info(f"Folder scanned: {folder} | Files found: {len(files)}")

3. LOGS USED IN THE PROJECT
Folder scan:
logger.info(f"Folder scanned: {folder} | Files found: {len(files)}")

File organization:
logger.info(f"File organized: {file} -> {destination_file}")

Duplicate detection:
logger.info(f"Duplicate scan completed | Groups found: {len(duplicates)}")

Duplicate movement:
logger.info(f"Duplicate moved: {file} -> {destination}")

4. ACTIVITY HISTORY API
FastAPI endpoint:
GET /organizer/activity

The endpoint reads activity.log and returns:
{
    "status": "success",
    "activities": [...]
}

activities.reverse() is used so the newest activity appears first.

5. REACT INTEGRATION
Axios calls the API:
export const getActivity = async () => {
    const response = await api.get("/organizer/activity");
    return response.data;
};

React stores activities with:
const [activities, setActivities] = useState([]);

The Activity History button calls the API and the returned entries are displayed in the UI.

6. COMPLETE DATA FLOW
File operation
    -> logger.info()
    -> activity.log
    -> FastAPI /organizer/activity
    -> Axios
    -> React
    -> Activity History

11. VIVA / INTERVIEW QUESTIONS

Q1. What is logging?
A. Logging is recording important events generated by an application.

Q2. Why is logging used in Smart File Organizer?
A. To record scans, organization, duplicate detection and duplicate movement for tracking and debugging.

Q3. Which Python module is used?
A. The built-in logging module.

Q4. What does logger.info() do?
A. It records an informational message in the configured log destination.

Q5. Where are logs stored?
A. backend/logs/activity.log

Q6. Why is pathlib used?
A. It provides a convenient object-oriented way to work with filesystem paths.

Q7. Why is reverse() used?
A. To show the latest activity first.

Q8. How does React get activity history?
A. React sends a GET request to /organizer/activity using Axios.

Q9. Why is logging useful for debugging?
A. It provides a record of what happened, helping locate problems.

Q10. What happens if activity.log does not exist?
A. The API returns an empty activities list.

Q11. Why is the move logged after shutil.move()?
A. To record the action only after the move succeeds.

Q12. Difference between logging and print()?
A. print() is mainly temporary console output; logging provides structured and configurable records.

Q13. What is INFO level?
A. It represents normal informational application events.

Q14. What is the purpose of Activity History?
A. To let users see previous operations performed by the organizer.

Q15. Can logs be stored in a database?
A. Yes. A future version can store activity records in SQLite using SQLAlchemy.
